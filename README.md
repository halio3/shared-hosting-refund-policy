## 共享主机是什么，适不适合你

共享主机就是常说的虚拟主机，一台物理服务器被分隔成若干份单独出售，用户之间共用 CPU、内存这些资源，所以便宜。它基本只干一件事：托管网站。个人博客、流量不大的企业官网，是它最典型的使用场景。

代价也很清楚。性能上限低，大流量网站撑不住；大多数虚拟主机用共享 IP，你的网站 IP 和别人的完全一样，想要独立 IP 也有，但价格贵不少。

系统方面，市面上多数商家只提供 Linux 主机，跑 WordPress、Discuz! 这类 PHP 程序没问题；Windows 主机主要面向 ASP.NET 程序，按你网站的编程语言选就行。

备案问题一句话说清：国内虚拟主机需要备案，香港、美国这些海外机房的主机不需要，付款后直接就能托管网站。很多人选海外主机，图的就是省掉这一步。

## 下单之前，最后确认四件事

1. 网站程序和系统要匹配。WordPress、Discuz! 这类 PHP 程序选 Linux 主机；只有 ASP.NET 程序才需要 Windows 主机，而多数商家只提供 Linux。
2. 备案问题想清楚。国内主机需要备案，香港、美国等海外机房免备案，付款后直接建站。
3. 免费域名只管首年，之后按原价续费；如果在退款期内取消，域名费用可能从退款里扣。
4. 支付方式提前确认。部分商家支持支付宝和银联，比如 Hostinger、bluehost 的香港机房；付款不顺的商家再便宜也够折腾。

## 常见问题

**共享主机和 VPS 有什么区别？**

VPS 把 CPU、内存、存储空间完全分隔开，每台都有独立 IP，可以当成一台独立服务器用，除了建站还能干别的事；虚拟主机是多人共用一台服务器的资源，性能和权限都有限。VPS 性能更好，价格一般也贵一些。

**海外共享主机需要备案吗？**

不需要。香港、美国等海外机房的主机，购买后直接就能托管网站；需要走备案流程的是国内虚拟主机。

**一个共享主机套餐能放几个网站？**

看套餐标注。InMotion 的三档分别是 2 个、10 个和 40 个网站；InterServer 不限制托管网站数量。下单前把这一项看清楚，超出后再升级，成本比一开始选对要高。
